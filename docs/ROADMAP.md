# Roadmap — Worktrace

> This roadmap records high-level milestones only. Detailed sprint tasks
> are defined in their respective sprint briefs once approved.

## Milestone Sequence

### Pre-S0 — Repository & Documentation Baseline ✅ *(current)*

- Establish project root and Git repository.
- Create essential project documentation.
- Define scope, decisions, and product direction.
- Connect GitHub remote repository.
- **No application code.**

### S0 — Application Foundation *(next, pending approval)*

- Flutter project scaffolding.
- Core project structure and module organization.
- Drift database setup with initial schema (tasks + snippets).
- Riverpod provider architecture baseline.
- Adaptive theme configuration.
- Minimal navigable shell (no polished UI).
- **Goal:** A buildable, runnable app skeleton with a working data layer.

### S1+ — Feature Sprints *(future, requirements TBD)*

- Task management feature (CRUD, status, due dates).
- Code snippet feature (save, tag, search, syntax highlighting).
- Resumability and recent-activity views.
- Polish, accessibility, and onboarding.
- Testing and quality gates.

### Post-V1 — Expansion *(speculative)*

- Cloud synchronization.
- Cross-platform targets.
- Advanced search and organization.
- Data export/import.

## Important Notes

- Sprint S0 and beyond will only begin after their scope and acceptance
  criteria are formally approved.
- Do not treat speculative milestones as commitments.
- This roadmap will be updated as decisions are finalized.
