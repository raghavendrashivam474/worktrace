## Architecture Decisions

| Decision | Rationale |
|----------|-----------|
| Reused `snippetListProvider` | No parallel state systems (DEC-011) |
| Discovery state is presentation-local | Matches `tasks_screen.dart` pattern; no need for global state |
| `@DataClassName('SnippetRow')` | Avoids collision with domain `Snippet` model (DEC-012) |
| `PopupMenuButton` for language filter | `DropdownButtonFormField` overflows at 320px; PopupMenuButton is adaptive |
| Container tag instead of Chip in cards | Chip has internal minimum size from stadium shape; Container is unconstrained |

## Known Limitations

1. **Debug APK only** — release/profile builds not attempted (signing config required)
2. **No integration tests** — widget tests cover UI flows but not full app lifecycle
3. **No performance benchmarking** — list virtualization via `ListView.builder` should handle large collections, but not stress-tested beyond 10 items
4. **Search is in-memory** — acceptable for local-first; would need SQLite FTS for 10k+ snippets
