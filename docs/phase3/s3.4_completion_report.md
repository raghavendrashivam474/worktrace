## S3.4.A — Transactional Import

### Problem
`PortabilityService.importWorkspace()` inserted records individually with
per-record try/catch. A failure mid-import left a partially imported workspace
with no rollback path.

### Solution
- Added `AppDatabase _db` to `PortabilityService` constructor.
- Wrapped the entire import body in `_db.transaction(() async { ... })`.
- Removed per-record error swallowing — failures now propagate and roll back
  the entire transaction.
- All three repositories (`TaskRepository`, `SnippetRepository`,
  `TaskSnippetLinkRepository`) share the same `AppDatabase` instance via
  `databaseProvider`, so Drift's transaction automatically covers all writes.

### No ADR required
No repository contracts changed. No schema changes. The transaction boundary
is an internal implementation detail of the service.

### Rollback tests (3 new)
All use real SQLite `RAISE(ABORT, ...)` triggers to cause genuine database
failures inside the Drift transaction:

1. **Mid-import failure rolls back all writes** — task inserted before the
   failure is verified absent after rollback.
2. **Original data survives rollback** — pre-existing tasks, snippets, and
   links remain intact.
3. **Subsequent valid import succeeds** — database is usable after a failed
   import attempt.

## S3.4.B — Real Migration Replay: v2 → v3

### Problem
The Phase 3 report recorded schema version 3 tests but no complete migration
replay from a real version 2 database.

### Solution
Added a genuine v2→v3 migration test that:
1. Creates a real v2 schema (tasks + snippets) using raw `sqlite3`.
2. Inserts representative data with realistic timestamps.
3. Sets `PRAGMA user_version = 2`.
4. Opens the database through the production `AppDatabase` path.
5. Verifies all pre-existing data survives.
6. Verifies the new `task_snippet_links` table exists and works.
7. Verifies FK cascade on task deletion.
8. Verifies FK cascade on snippet deletion.
9. Verifies duplicate `(taskId, snippetId)` prevention.
10. Verifies dangling FK references are rejected.

### No historical migrations modified.

### Files changed
- `test/features/snippets/data/migration_test.dart`
